# Specification

## Summary
**Goal:** Improve the Success Criteria module tab controls so users can clearly identify hover/focus/selected states, and ensure “Impact” and “90-Day Plan” are distinct buttons that navigate to the correct sections.

**Planned changes:**
- Add clear hover, focus, and selected (active) visual styles to all Success Criteria tab buttons (the four success criteria tabs plus “Impact” and “90-Day Plan”), ensuring no layout shift and supporting both light and dark modes.
- Ensure “Impact” and “90-Day Plan” render as two separate, readable button/tab elements across viewport sizes with no label overlap.
- Fix navigation so “Impact” scrolls only to `#impact` and “90-Day Plan” scrolls only to `#roadmap`.

**User-visible outcome:** Users can see which Success Criteria tabs are interactive, hovered, focused, and selected, and can reliably use separate “Impact” and “90-Day Plan” buttons to scroll to the correct sections on any device.
