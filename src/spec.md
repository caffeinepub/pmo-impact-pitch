# Specification

## Summary
**Goal:** Create a responsive, single-page interactive interview-pitch website that presents the candidate’s PMO narrative and achievements in a crisp, executive-style format.

**Planned changes:**
- Build a single-page layout with clear navigation to: Executive Pitch (hero), About Me, Success Criteria, Impact, and 90‑Day Roadmap.
- Implement the Executive Pitch hero with one concise PMO/portfolio-governance pitch paragraph, a call-to-action (e.g., “Explore impact”), and subtle “Tailored for Sanjeev & Martin” text.
- Add an “About Me” section highlighting 7 years of PMO experience, core strengths, and a scannable alignment list mapped to the four success criteria.
- Create an interactive Success Criteria module with 6 buttons/tabs: four success criteria, plus “Impact” and “90‑Day Roadmap Plan”; only one view visible at a time.
- For each of the four success criteria, display exactly 3 STAR stories (Situation, Task, Action, Result) based on the provided initiatives.
- Implement an “Impact” view with at least 12 concise, highly visual before/after statements (e.g., cards in a two-column Before vs After layout).
- Implement a “90‑Day Roadmap Plan” view split into Days 1–30, 31–60, 61–90 with PMO-relevant actions focused on governance control points, lifecycle integrity, automation/validation, dashboards, and enablement/training.
- Add a dedicated optional “Reference/Notes” collapsible section (or modal) that displays the two uploaded images as reference material without identifying or asserting who is in them.
- Apply a coherent, professional “executive governance / operational excellence” visual theme that is not primarily a blue+purple palette.

**User-visible outcome:** Visitors can scroll or navigate through a polished, mobile-friendly PMO pitch with interactive success-criteria tabs, skimmable before/after impacts, a clear 90‑day plan, and an optional reference panel showing the uploaded images.
